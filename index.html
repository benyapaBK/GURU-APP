• ประสบการณ์แบบ Mobile-first ไหลลื่น
PERSONA 02 // AGE 25–34
Creative Professional

นักออกแบบ มาร์เก็ตเตอร์ ครีเอเตอร์ นักพัฒนา ที่กำลังค้นหาแรงบันดาลใจและข้อมูลอ้างอิง

สิ่งที่ต้องการ:
• Interactive Graph เจาะลึกโหนดข้ามศาสตร์

• ดาวน์โหลดชุดข้อมูล (JSON / Graph API) ไปต่อยอด
PERSONA 03 // AGE 30–40
Lifelong Learner

คนทำงานและพ่อแม่รุ่นใหม่ อยากรู้ที่มาของสิ่งรอบตัว เช่น สุขภาพ อาหาร และภูมิปัญญาโบราณ

สิ่งที่ต้องการ:
• ความน่าเชื่อถือ แหล่งอ้างอิงตรวจสอบได้ใน 1 คลิก
• ตัวอักษรที่อ่านสบายตา (IBM Plex Sans Thai)
• บทเรียน Everyday Takeaways ที่ใช้กับครอบครัวได้

GRM-2026-EXEC-006 // DATA ONTOLOGY
KNOWLEDGE ARCHITECTURE

บูรณาการข้อมูลจาก 4 แหล่งใหญ่ สู่เครือข่ายความรู้ที่เข้าถึงได้ทุกคน (WCAG Color Blind Friendly)
⚡
3-Second Executive Summary
รวบรวม Books, Textbooks, Databases, และ Community Knowledge แยก 6 หมวดด้วยคู่ “สี + ทรงเรขาคณิต” และเชื่อมด้วย 3 ความสัมพันธ์หลัก: Influenced (เส้นทึบ), Derived From (เส้นประ), Used In (เส้นจุด)
ACCESSIBLE CATEGORIES (SHAPE + COLOR)
○ วิทยาศาสตร์ (Science)
⬡ ประวัติศาสตร์ (History)
□ เทคโนโลยี (Technology)
△ วัฒนธรรมและภูมิปัญญา
◇ ธรรมชาติและชีวิต
◎ ศิลปะและการออกแบบ
RELATION TYPES:
• influenced (มีอิทธิพลต่อ): เส้นทึบ 1px (ทึบ 30%)
• derived_from (พัฒนามาจาก): เส้นประ (Dashed line)
• used_in (นำไปใช้ใน): เส้นจุด (Dotted line)
SELECTED CAPTION:
มุมมองที่ 1: ภาพรวมแนวคิดสถาปัตยกรรม (Conceptual Overview)
แสดงการรับเข้าจาก Books, Textbooks, Databases, Community สู่แก่นกลาง Knowledge Graph
